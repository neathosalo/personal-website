## 二、网站结构

### 2.1 页面模块（基于Kimi_Agent方案）

| 模块 | 文件名 | 内容要点 |
|------|--------|----------|
| 导航栏 | Navbar.tsx | 老邢品牌Logo、导航菜单（首页、关于、经验、作品、服务、联系） |
| 首页英雄区 | Hero.tsx | 姓名、职位、Slogan、CTA按钮 |
| 关于我 | About.tsx | 个人简介、核心能力、照片/头像 |
| 工作经历 | Experience.tsx | 职业生涯时间线、关键项目 |
| 项目/作品 | Portfolio.tsx | CMMM评估案例、数字化转型项目 |
| 服务内容 | Services.tsx | 服务项目、服务流程、联系方式 |
| 联系我 | Contact.tsx | 邮箱、LinkedIn、GitHub、留言表单 |
| 页脚 | Footer.tsx | 版权信息、社交链接 |

### 2.2 技术栈
- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **组件库**: shadcn/ui
- **状态管理**: React Hooks
